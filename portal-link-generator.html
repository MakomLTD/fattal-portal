📖 מדריך מהיר

📊 מבנה הגיליון

כל שורה = פרויקט אחד. עמודות חובה:

  • client_id — מזהה הלקוח (באנגלית)
  • token — סיסמה לגישה
  • active — TRUE / FALSE
  • project_name, status, lat, lng
  • progress — 0–100 (אחוז התקדמות)
  • risk — נמוך / בינוני / גבוה

🕒 צעדים להפעלה

  1. פתחו script.google.com → פרויקט חדש
  2. העתיקו לתוכו את Code.gs ואת index.html
  3. עדכנו SPREADSHEET_ID בקוד
  4. פרסו (Deploy → New deployment → Web App → Anyone)
  5. הדביקו את ה-URL בשדה למעלה
  6. לכל לקוח: לחצו "העתק Embed" והדביקו ב-Google Sites
